# 重写之前先做一次代码考古

要从零重写一个系统，手上还躺着 8 个自己写的旧仓库、3 种语言、其中一个是被明确废弃的两万行实现。通常只有两种默认做法：

- **把旧代码拷过来慢慢改**——连同它的架构一起继承，重写变成了重构；
- **当它不存在**——每一个坑重新踩一遍，学费再交一次。

第三条路是：**在写第一行新代码之前，把"读旧仓库"立项成一次正式的、只读的考古任务**，产出不是代码，是一份不变量与测试用例清单。

这份文档记的是那次考古的做法、它产出了什么、以及哪些规矩让它没有退化成一堆"看起来很有道理"的读后感。

---

## 一、六条让考古有用的规矩

### 1. 物理上只读

被考古的旧分支不 checkout、不建 worktree，而是 `git archive <ref> | tar -x -C <临时目录>` 导出到临时区再读，主仓库零改动。

好处有两个，第二个更重要：既不会误污染工作区，也**掐掉了"顺手把这个文件搬过去"的冲动**。手边没有一个可以直接编译的旧工程，就只能去写"它保证了什么"。

### 2. 产出必须与语言无关

任务书里写死：产出定位是**与语言/技术栈无关的不变量、状态机、断言清单**，**语言选型不评**。

于是报告里的内容不是"它这么写的"，而是"这件事必须为真"：

> **不变量**：封存动作是「先写临时目录 → fsync 文件 → fsync 目录 → 原子改名 → fsync 父目录」。少任何一个 fsync，断电后都可能得到"目录已存在但内容是半截的"。

> **不变量**：哈希必须在落盘之后**从文件重算**，不能用写入时顺手算的那个。否则"内存正确、磁盘损坏"这一类检不出来。

> **不变量**：回执必须是整个流程的**最后一个写动作**。任何把它提前的优化都会制造"上游以为成功、中心其实没有"的静默丢失。

这种句子可以逐条搬进任何语言的新实现，也可以逐条写成测试。

### 3. 每一条结论带证据等级

报告开头定义三个标记并全文贯彻：

- **【码】** = 亲读代码确认的事实，**带文件:行号**；
- **【文】** = 旧仓库文档的自述，未验证；
- **【推】** = 调查者本人的推断。

这是整套做法里性价比最高的一条约定。它让后来的读者一眼分得清哪句话可以直接据以行动、哪句话需要自己再验一遍。没有这个标记，一份长报告里的推断会在传递两轮之后变成"据说是实测的"。

同样的纪律还有一条更朴素的形态：**报告自己纠正任务书**。这次考古的任务书里写错了一个分支名（本地没有那个分支，只有对应的远端引用），报告第一屏就把它标出来并给了可用的引用形式。**把上游的错误当成产出的一部分交回去**，比默默绕过去有用得多。

### 4. 交付物里必须有一份测试用例清单

报告第二章是 76 条"故障场景 → 断言 → 原测试名"的表格，并且明说：

> **这部分的移植价值高于实现本身**——它们是把上述不变量钉死的钉子。

原因很实际：**实现跨不过语言，测试用例可以。** 举几条真实的条目（都与具体语言无关）：

| 故障场景 | 断言 |
|---|---|
| 中心已收下数据，但崩在"写回执之前"，随后中心也重启 | 重传后回执被补写、校验通过；**中心目录下只有一份** |
| 载荷被改了 1 个 bit（**长度不变**） | 中心拒收；**中心侧不存在半成品残留** |
| 租约被 B 接管后，A 继续心跳 / 提交进度 / 报完成 | 三个**全部**被拒；A 的本地活动任务集合立刻变空 |
| 租约被接管后，A **重启进程** | 重启后恢复出来的活动任务仍为空（**丢租约必须是持久化的，不能重启复活**） |
| 上传失败后重启，数据已封存但未被确认 | 恢复后**不再调用外部数据源**（用请求计数器断言只调用过一次），直接上传既有数据块 |
| 接收端本地序号从 1 跳到 9 | **绝不产生"源端有缺口"这条事实** |
| 保留期未到就尝试删本地 | 不删除，返回"保留期未到"——**这是正常状态不是错误** |

顺带被挖出来的还有三条测试基础设施习惯，也一并继承了：**时钟一律注入**（全仓无 sleep）、**定时器也注入**（长任务的续租行为可确定性驱动）、**用请求计数器断言"没有重复调用外部 API"**（验证"重启恢复不重采"最直接的手段）。

### 5. 必须有"明确不要照抄"和"它根本没有"两章

只写"值得移植"的考古报告是危险的，因为读者会默认没被点名的部分是安全的。这份报告的第三章列了 12 条**明确不要照抄**，每条带原因；结尾还单列了一节**"不是不要照抄，是没得抄"**——全仓 grep 确认旧实现完全没有的三块能力，必须从零设计。

第二类比第一类更容易被漏掉，而且更危险：**一个在别处很成熟的系统，会让人默认它在某个维度上也有覆盖。** 明确写下"这里是空白"，才不会有人在重写时以为"照着搬就行"。

### 6. 开放问题是交付物，不是失败

报告最后留了 7 条调查者**明确无法自行决定**的问题，指名交给架构角色或负责人，例如：

- 常驻流与租约的根本矛盾该怎么解（这一条后来直接催生了双控制面）；
- "同一个公网出口只允许一个节点出网采集"这条规则应该放在模型的哪一层——它既不是能力匹配（那是 per-task 的），也不是配额（那是可分配额度）；
- 哪些数据类型需要进跨源规范化、哪些只需原样存档；
- 幂等表与审计表的保留策略——五年期必须有 GC，且**幂等记录的过期时间必须长于任何客户端的最大重试窗口**，否则会出现"重试时幂等记录已被清掉 → 重复执行"。

一份把所有问题都"解决"了的考古报告，多半是在替不该它做的决定做决定。

## 二、对抗性核验：这批报告里 30 多条结论被否决了

这次考古不是孤立的，它属于一轮多角色并行研究（考古、旧仓挖掘、技术选型调研、采集专家、数据质量、风险审计、架构等）。真正让这批材料可用的，是配套的一条制度：

> **每份报告都配一份独立的核验报告**，由另一个角色逐条对照规范文档、旧引用与外部来源验证。**核验判为"冲突 / 无据"的结论一律不得采信。**

结果：30 多条结论被否决，其中包括**疑似编造的数字**。各份报告的核验结论差别很大——考古报告"零冲突、行号逐条核实、原样采纳"；另几份则是"方向可采纳，但某几处外部数字有冲突，修正前不得引用"。

没有这一层，一个大型研究语料会变成**引用洗白机**：一个数字只要被写进文档、再被另一份文档引用一次，就获得了它本来没有的权威性。

配套的第二条制度同样重要：

> 研究目录顶部写明**"研究材料快照，不是规范"**，权威级别**低于**规范文档；结论要生效，必须先落进对应的规范文件，再按那些文件执行。

否则一份几千行的研究产出会在无人宣布的情况下变成影子规范，而且是一份没有修订记录、没有推翻条件的影子规范。

这轮研究还留下了一条自嘲式的记录：某条"某历史数据在某日停更"的结论后来被复测推翻——真相是对象存储的列桶结果在若干个 key 处被**静默截断**造成的假象。同一形状的错误在这个仓库里出现过三次，于是"必须翻页到底、确认没有截断标记才允许下结论"被升级成一条硬规则，并在主规则文件里注明：**这不是洁癖，是这个项目反复栽跟头的具体位置，而且每次都表现为"有数据、不报错、结论看起来合理"。**

## 三、这次考古实际换来了什么

**原样采纳的**：原始数据不可变闭环（内容寻址 + 自证 manifest + 不可变/可变分文件）、三元围栏租约状态机、惰性过期（判定放在每次读写入口，而不是后台清扫器——好处是行为可用注入时钟确定性测试，且不存在"清扫器没跑导致任务永久卡住"这一整类故障）、中心身份/纪元围栏、去重即证据的账本、归档四条件才允许删本地。

**采纳但方向修正的**：

- 配额记账键从"按节点"改成"按出口身份"——旧实现按节点记账，与新一代"限速预算按公网出口计"的拍板冲突；
- 质量事实体系里补上"推送保真度"维度——旧实现完全没有这个概念，而实测表明不同交易所的推送策略差异巨大，不带这个维度的跨源聚合是没有定义的；
- 补上"换模态对照"（推送 vs 轮询）这类事实——旧实现把"双路冗余"硬编码成了完整性证据，而这是错的（见《被放弃的设计清单》）。

**最值钱的一条，是一个类型级约束**：旧实现把"接收端序号"和"源端序号"做成了**不同的类型**，只有源端序号才允许产生"有缺口"这条事实。报告对它的评价是：

> **移植这条，价值高于移植任何代码。**

因为它把一条纪律从"文档里的要求"变成了"在类型层面根本说不出口的话"。没有源序号时，"我漏了"这句话写不出来。

**还有一类产出是负资产的正向利用**：上一代的一个游标 bug 被直接指定为新一代的**反例 fixture**——不是"记得别这么写"，而是变成测试里的一个具体输入。

## 四、可迁移的结论

1. **重写之前立项一次只读考古。** 它便宜（一次性），而且是**唯一还来得及据此行动的时刻**——代码写下去之后再发现旧系统解决过同样的问题，那份发现已经不值钱了。
2. **物理只读。** 导出到临时区读，不 checkout、不建 worktree。既防污染，也防"顺手搬一下"。
3. **产出是不变量与测试用例，不是代码片段。** 测试用例跨语言，实现不跨。
4. **每条结论标证据等级并带定位。** 【实测 / 文档自述 / 推断】三分，缺了这个，长报告会把推断洗成事实。
5. **必须写"不要照抄"和"它根本没有"两章。** 后者更容易漏，也更危险。
6. **开放问题要留给有权决定的人。** 考古者不该顺手把架构决定做了。
7. **给研究产出配一层独立核验，并明确"核验不过的不得采信"。** 同时把研究目录的权威级别写在它自己的开头——它是依据档案，不是规范。
8. **让纪律成为类型，不要让它只是约定。** 能在类型层面说不出口的错误，就不需要靠评审去抓。
