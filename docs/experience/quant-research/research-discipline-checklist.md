# 研究纪律检查清单：从假设到部署的强制门禁

这份清单的每一条都是真实踩坑换来的，不是从教科书抄来的。它把多个独立研究项目各自总结出的规则合并成一套统一流程：**假设 → 特征 → 信号 → 回测 → 稳健性 → 前向观察 → 部署**，每一关都有明确的拒绝条件。

使用方式：**默认拒绝**。一条候选策略必须逐关通过，没通过的关卡不能"下次再补"。

---

## 阶段 0：假设登记

- [ ] **先写下假设，再写代码。** 假设必须包含：市场机制上的理由（为什么这个 edge 应该存在）、预期持仓周期、预期信号频率。
- [ ] **先问"打得过无脑买入持有吗"。** 用同一套方法论测过的等权买入持有基准，风险调整后往往比辛苦挖出来的策略还好或相当。任何新策略的第一个对照组是 B&H，不是零。
- [ ] **确认这条路的成本结构能支撑它。** 高频/微观结构类信号即使统计上成立，散户 taker 执行往往净值为负；这类假设在立项时就该问清楚"需要 maker 挂单还是低延迟才能变现"。

---

## 阶段 1：数据与特征

- [ ] **G1 数据窗口**：少于 30 天的数据不能做 alpha 验证，只能当探索性 EDA。
- [ ] **G2 禁用 expanding 统计量**：任何标准化、分位数、阈值必须 rolling。
- [ ] **G3 时点纪律（PIT）**：任何选标的/评分/regime 判定，只能使用该时点已经可见的数据。
- [ ] **G4 数据管道自检**：0 事件 / 0 信号 / 全 NaN 默认是 bug，先自检再下结论。
- [ ] **G5 信号频率合理性**：全样本信号频率异常高（例如超过一半时间都在发信号）→ 判为伪策略，拒绝。
- [ ] **特征级 IC 先行**：用 Spearman IC + 非重叠采样 + 分块 IC-IR 稳定性先筛特征，再把幸存的特征交给策略级验收。

---

## 阶段 2：回测构造

- [ ] **G6 摩擦优先**：一切回测强制包含进场延迟、手续费、滑点、资金费计提。无摩擦的回测结果一律作废，不进结论库。
- [ ] **G7 执行一致**：回测、重放、实盘必须走同一条信号计算路径（同一份代码、同一份参数），不允许两边各写一份。
- [ ] **G8 权益路径**：带杠杆的回测必须实现维持保证金强平并报告强平次数。
- [ ] **对照基准**：每个窗口附带统一口径的基线（例如 mid-hold、或未加过滤的原始信号），改动只能和基线比，不能只看绝对值。

---

## 阶段 3：统计验收

- [ ] **G9 最小样本**：短周期 n ≥ 30 笔，月级 n ≥ 10。不足只能标"观察"，不能标结论。
- [ ] **G10 多重检验记账**：诚实报告"这个参数组合是从多少个候选里选出来的"，并做 n_trials 敏感性扫描；扫过 20 组以上参数必须报告 FDR 或 Bonferroni/Holm 校正。
- [ ] **G11 selection-aware 一票否决**：DSR / PBO 不过则拒，不看曲线。经验门槛：DSR ≥ 0.95、PBO ≤ 0.5、DSR 的 p 值 ≤ 0.05。
- [ ] **G12 OOS 同符号**：训练集漂亮、测试集为负 → 拒。不允许用"样本外只是差一点"来通融。
- [ ] **G13 滑点敏感性**：0 / 5 / 10 bps 三档都要跑；10 bps 后 alpha ≤ 0 → 拒，或降频重做。
- [ ] **G14 参数平台**：最优点必须坐落在一片高原上；孤立尖峰 → 拒。极端参数敏感性本身就是拒绝理由。
- [ ] **G15 多标的一致性**：至少 3 个标的测试，2 个失败 = 单标的假象，不能外推。
- [ ] **G16 Regime 分层**：牛/熊/横盘分别统计。跨 regime 表现分裂（短期神级、长期灾难）= 策略本身不工作，不是"运气不好赶上坏 regime"。
- [ ] **G17 收益集中度**：若大部分收益集中在极短的时间窗口内 → 默认 regime 巧合，必须主动反证。
- [ ] **G18 全周期 ≠ 滚动窗口**：多年整体 Sharpe 不等于 N 个 walk-forward 窗口的 Sharpe。总体均值会掩盖近期负 alpha，必须拆成滚动窗口逐个看，并**重点看最近 1–2 个窗口**。

---

## 阶段 4：稳健性与组合

- [ ] **G19 变体不继承结论**：换回看窗口、调仓频率、持仓数量都算新策略，必须重跑全流程。
- [ ] **G20 二次融合必须证明自己**：加任何过滤层，必须在同一套 walk-forward 口径下打赢未加过滤的基线；打不赢就撤掉。
- [ ] **G21 组合前先看相关性**：多条腿组合之前先算日频收益相关矩阵，相关系数不够低（经验门槛 ρ < 0.3）就只留最强的那条，不要为了"分散"而分散。
- [ ] **G22 警惕伪分散**："跨资产"未必等于"多个独立信息源"。如果标的之间长期相关性极高，分散化收益比表面上小得多，策略的真实机制可能只是"捕捉相对强弱的时机差"。

---

## 阶段 5：前向观察（最容易被跳过、也最关键的一关）

历史验证通过 **不等于** 现在还有效。这是整份清单里被独立印证次数最多的一条。

- [ ] **G23 CONDITIONAL ≠ VALIDATED**：即使全套统计检验通过，也必须再做至少 30 天的 paper trading，验证"最近这段时间"的表现。
- [ ] **G24 双重毕业门槛**：历史验证通过 **并且** 最近一段前向窗口的实测 Sharpe 为正且超过门槛。只满足前者的策略，必须停在 dry-run。
- [ ] **G25 前向观察要有存活证明**：paper 进程"还在跑"不等于"还在工作"。必须监控信号产出本身（空文件、长期无新信号 = 已死），不能只看进程是否存在。
- [ ] **G26 Backtest 是必要不充分条件**：live/paper 才是真正的检验。一个在高波动区间回测全正的策略，在当前低波动区间可能长期不发信号——这本身是设计符合预期，但也意味着"回测很好"完全没有兑现路径。

---

## 阶段 6：部署门禁

一个统一的、可执行的 deploy gate 应该同时满足：

```
最小交易笔数  AND  总收益 > 0  AND  DSR 显著（p ≤ 0.05）
AND  walk-forward 衰减 ≤ 阈值  AND  最近前向窗口 Sharpe > 门槛
AND  强平次数 = 0（在真实维持保证金假设下）
AND  连续若干天 dry-run 无报错
```

配套的运行时检查（每次决策前）：

- 验证层判定通过（DSR / PBO）
- meta-labeling 二阶段置信度达标
- 反 spoofing 检测未告警
- 情绪/心理过滤器允许（极端情绪不逆势）
- 健康监控状态非 critical

**并且写死一条：未过 deploy gate 之前禁止启用实盘。** 这条在我们的历史里被遵守过，也被违反过——违反的那次是一个代码 bug 导致的真钱小额亏损，事后的修复方案是把实盘开关强制锁死，并要求先在测试网连续无故障运行若干天才能重新开放。

---

## 阶段 7：仓位计算前的独立检查

即使策略过了 deploy gate，仓位公式还有自己的一套前置条件：

- [ ] 样本量足够（经验门槛：≥ 100 笔）才谈 Kelly 类公式；
- [ ] 用 Ljung-Box 之类的检验确认收益序列的自相关性；
- [ ] edge 的半衰期不长于数据历史的四分之一；
- [ ] 不要用历史最大回撤定杠杆——块自助算出的尾部最坏回撤经常接近历史最大回撤的两倍。

---

## 三条元规则

1. **负面结论照样入库。** 只展示赢家的知识库是营销，不是研究。被证伪的东西必须记录，且要记录"为什么"。
2. **结论要带可复现的完整记录**（代码 + 数据快照 + 参数 + 环境）。找不到这套记录的历史结论，一律打问号。
3. **"验证过"永远带时间戳。** edge 会衰减，市场会适应，未来永远是样本外。
