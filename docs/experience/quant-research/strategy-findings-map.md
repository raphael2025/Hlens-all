# 策略结论地图：什么被证伪了，为什么

这份文档是多个独立研究项目（不同的数据源、不同的回测引擎、不同的时间、不同的执行者）交叉验证之后的结论汇总。它刻意**不给参数、不给业绩数字**——因为这些结论里真正可复用的部分是**机制和失败原因**，不是某一组数字。

判定口径：一条策略要被标为"有效"，必须通过《反过拟合方法论》里的全套 selection-aware 检验，并且通过最近窗口的前向观察。任何没有对应可复现验证记录的判定，只能标"未验证"，不能标"有效"。

---

## 一、被系统性证伪的类别

以下类别在**至少两个互相独立的测试**中得出一致的否定结论。独立性是这份清单的价值所在——单次否定可能是实现方式的问题，多次独立否定则指向类别本身。

### 1.1 经典技术指标择时

均线交叉（SMA/EMA 各种组合、斜率背离、回踩深度分类、快线周期全扫描）、MACD、RSI 均值回归、布林带 + ADX 均值回归。

**失败模式**：样本内可以调出漂亮的 Sharpe，但 PBO 极高（样本内冠军在样本外一贯变垃圾），样本外经常直接翻负。RSI 类在某些标的上样本外崩塌得最彻底。

**一个值得单独记住的假阳性**：MACD + 道氏结构确认（破前高不破前低）是整轮研究里**唯一一个通过了独立回测框架交叉验证**的技术信号，但在真正的样本外时段依然崩溃。它是"最容易被误判为找到了"的那一类。

### 1.2 网格交易

三个主流标的上样本内、样本外**全部为负**，且块自助给出的尾部回撤是灾难级的。网格的本质是卖波动率、无止损，在趋势行情里结构性亏损。

### 1.3 图表形态识别 + 突破成交量确认

一个完整项目（形态识别器 + 突破放量确认 + 真实账本纸面模拟 + 复利蒙特卡洛 + 连续加权定仓）的最终判决是**证伪**。

- 形态信号本身在"立即进场"口径下胜率恰好踩在盈亏平衡随机线上，扣摩擦净负——**规则伪标签的形态不预测方向**；
- 真正有效的成分是"突破那一刻是否放量"这个机制，而不是形态识别器本身（那套模型几乎是多余的）；
- 但整条线本质上是**牛市 beta，不是抗 regime 的 alpha**——收益集中在特定牛市年份，近期几乎打平且盈利高度集中在单个月份。

**顺带的通用结论**：趋势/动量/突破这一大类，Sharpe 普遍活在历史上的几段强趋势期，当前 regime 下集体衰减。

### 1.4 SMC / ICT 类"聪明钱结构"方法

被系统性否决。民间流传的高胜率说法没有任何可复现的回测依据，属于"未经验证的说法"，不是新证据。这类方法的回测极易通过标注时点作弊（把只有事后才知道的结构点标在当时）。

### 1.5 资金费率 carry（至少在某一类实现下）

这一条的意外价值最高：carry 在**理论上**有结构性风险溢价支撑，直觉上"应该 work"。实测结果是三个主流标的全部没通过——有的是 PBO 为 0 但 DSR 不够，有的是样本外基本打平。

**教训**：不能因为"理论上应该有 carry"就把它当成下一个该做的方向。要么是具体实现（delta-neutral 近似）有问题，要么是这个思路在这种测试方式下本身就不稳定。**理论上的合理性不构成证据。**

补充警示：在加了真实维持保证金强平约束之后，重仓资金费率腿的组合会从"优秀"直接崩到接近零——纸面 Sharpe 和可生存性是两回事。

### 1.6 散户可执行的订单流/微观结构策略

订单簿失衡（OBI）、订单流失衡（OFI）、VPIN、micro-price、各种机构意图识别（诱多/诱空/吸货/派发/流动性测试）。

**这一类的结论比较微妙，值得完整表述**：

- 统计上的预测力**是真实存在的**（多档 signed OFI 对下一个 tick 中间价变化的解释力显著高于单档 OBI，学术公式谱系完整）；
- 但这是**做市商 / 亚秒级**的 edge。散户以 taker 方式下单，净值为负；
- 一个诚实的负结果案例：某订单簿信号做了长时间的真实 WebSocket 重放，十多组参数配置全部亏损，结论是"信号在一两百毫秒内就被市场消化掉了"；
- 加密市场还有自己的陷阱：撤单/成交比远高于传统市场（数量级差异），意味着瞬时 OBI 极不可靠，必须做平滑 + z-score 过滤才能防止被塞单/幌骗污染。

**结论**：不是"这条路没价值"，而是**"变现需要 maker 挂单能力 + 低延迟基础设施"**，这是一个在立项阶段就该想清楚的前提条件，而不是回测之后再发现。

### 1.7 其他被测过且不显著的信号

动量自相关、跨周期背离、成交量突增方向、资金费率拥挤度分位、隔夜时段季节性、HMM 隐马尔可夫状态的方向性预测、脱离均线/MACD 单独测试的结构信号、跨标的资金费率套利（信号密度太低）、低波动异象（很弱）。

## 二、幸存下来的那一类，以及它自带的警告

经过全套反过拟合检验之后，**在一批十几个配置的系统性验收里只有一个通过**：一类**截面动量**（在少数几个主流永续标的之间按相对强弱排序、定期调仓、持有相对最强者）。

即便如此，它也带着三条必须一起记住的限定：

1. **历史通过 ≠ 当前有效。** 同一条策略在全历史口径下检验结果极好，但最近半年的实测是明显负值。最终裁决是**不切真钱，继续 dry-run**，并设立"历史验证 + 近期前向 Sharpe"双重毕业闸门。
2. **它可能不是你以为的那个机制。** 逐行审计发现，一个被标为稳健的"截面动量"实现，实际上是单标的时序动量；而且某个参数是死参数，导致多重检验次数被虚增。**判决建立在对实现的逐行确认之上，不是对命名的信任。**
3. **"跨资产"未必等于真分散。** 主流大市值币种之间长期相关性极高，协整关系还会在减半、监管冲击附近退化。所以"为什么截面比单资产好"这个机制，可能更多是"捕捉相对强弱的时机差"而不是"多个独立信息源的组合"——这个认知偏差会直接影响对未来稳健性的预期。

## 三、几条跨类别的通用结论

### 3.1 简单粗暴 > 精细执行

多组独立测试（阻力位止盈、等固定时长回调入场、多周期精细组合）都显示"精细化执行"比"趋势确认后直接进场"更差。原因是加密市场最强的趋势往往不给回调机会，等回调等于踏空或追高。

### 3.2 买入持有是极难打败的基准

用同一套方法论测大盘股等权买入持有，风险调整后的表现比很多辛苦挖出来的加密策略还要好或相当。**任何新策略的第一个问题应该是"打得过无脑买入持有吗"。**

### 3.3 方向性择时在单一主流标的上没有可靠 edge

两套完全独立的研究（不同引擎、不同时间、不同方法细节）得出同一结论。这是目前交叉印证最强的一条负结论。

### 3.4 Alpha 衰减要按加密的速度预期，不是按股票

公开可得的历史参照显示：加密动量类 alpha 的衰减周期以周计（而股票以月计），套利类以天计。此外有多个具体的"公开即衰减"案例：某链上指标公开后预测力腰斩；某宏观数据发布时的短线策略在公开半年内胜率掉到盈亏平衡线附近；基础设施层面的改动（如反三明治攻击的私有交易通道）可以直接砍掉某类套利利润的大部分。

**推论**：任何新发现的 edge 都应该按"以周计衰减"来规划，而不是假设它能稳定几年。

### 3.5 成本损耗的量级参考

高频策略从毛 alpha 到净 alpha 的损耗量级在三到五成；低频链上策略在一到两成。做成本假设时，用这个量级校验而不是拍脑袋。

### 3.6 数据本身可能是脏的

有研究指出报告成交量中可能有很大比例是刷量。任何基于成交量的流动性因子都要留意这个偏差。

## 四、这份地图该怎么用

- **不要把它当禁区清单。** 它说的是"我们在这些数据条件、这些执行条件下，用这套方法论测不出可用的东西"，不是"这条路绝对不存在 edge"。
- **要把它当立项过滤器。** 如果一个新想法属于上面任何一个已被多次独立否定的类别，立项时就要先回答"这次和之前几次有什么本质不同"——新数据源？新执行能力？新时间尺度？答不上来就不要再花周期。
- **要把负面结论写进库。** 这份地图的价值几乎全部来自于"失败也被记录下来了"。
