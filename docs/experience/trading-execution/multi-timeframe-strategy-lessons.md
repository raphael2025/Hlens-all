# 多周期交易框架：一次"设计假设版 → 证据版"的全面改写

这份文档记录的是同一个多周期交易框架的两个版本之间发生了什么。

- **v0.3 是设计假设版**：三层周期分工（高周期定方向、中周期找结构、低周期触发入场），十几条形态规则，分批止盈，追踪止损，状态机管仓——一套听起来非常专业、也非常常见的设计。
- **v1.0 是证据版**：只保留在四年单品种数据上，经过样本内 / 样本外 + 随机基准 + 安慰剂检验后仍然成立的部分。

结果是：**v0.3 设计里的大部分内容在 v1.0 里被删掉了。**

下面是逐条的"什么活下来、什么死了、为什么"。所有数字都来自单一品种的历史回测研究，不是实盘业绩，也不构成任何建议。

---

## 一、最终活下来的东西，可以写成一句话

> 高周期通道放量突破定方向 → **立即**入场 → **只在方向反转时**离场 → 一个很宽的灾难止损兜底 → 仓位随波动率反向缩放 → 事件与瀑布窗口不开新仓。

其余一切（回调入场、结构管仓、分批止盈、追踪止损、细状态择时）在四年数据上**要么无信息，要么有害**。

---

## 二、死掉的设计，以及它们是怎么死的

### 2.1 低周期形态入场：携带的是负信息

三种经典入场形态（扫止损后收复 / 回调入场 / 假突破），16 种参数组合，**16/16 全部低于随机入场基线**。

不是"效果不明显"，是**负信息**——这些形态本质上是在动量末端追单。

这个结论在三次互相独立的检验里重复出现（形态择时、状态机择时、117 个特征的方向预测），每次都指向同一件事：**在一个方向已经确定的行情段内部，任何入场择时都不优于随机。**

### 2.2 多层出场：每加一层，砍掉一截尾部

原设计有三层出场：较窄的止损、达到 1.5R 平掉一半、以及均线追踪止损。

实测：

- 这三层的交易成本合计占掉每笔 R 的 **14%**；
- 更致命的是，**每加一层出场就砍掉一截收益分布的右尾**，这个现象在三次独立复现里都出现了。

趋势跟随系统的全部利润来自少数几段长趋势（实测约 13% 的交易贡献了绝大部分收益）。任何"锁定利润"的机制，本质上都是在对着利润来源开枪。

同样死掉的还有八个候选的"震荡退出"规则（无进展退出 / 停滞退出 / 趋势强度退出）：**全部失败，压住持仓必然砍掉捕获率。**

### 2.3 结构驱动的加减仓：样本外归零

用中周期结构打分驱动加仓减仓的状态机：

- 用它在段开始时选段，样本外 AUC = **0.54**（等于抛硬币）；
- 用它在回调点加仓，样本内是**负信息**，样本外是零；
- 案例回放里，它在一次大趋势的中途把仓位清光了。

### 2.4 均线 + 趋势强度指标定义的 regime：方向正确率 33%

用 EMA 排列 + ADX 定义的四态 regime（上涨 / 下跌 / 区间 / 震荡）：

- 段的**方向正确率只有 33%**；
- 被标为"震荡、不要交易"的状态，**恰恰是趋势启动的时刻**；
- 砍掉"区间"状态下的交易，并不改善单笔期望。

这是一个很值得记住的失败：这套 regime 定义在图上看起来完全合理（背景色块与肉眼判断的趋势/震荡区间吻合，人工目检没有发现明显矛盾），**但它对未来毫无预测力**。"看起来对"和"有信息"是两件独立的事。

### 2.5 那些"我明明见过很多次"的经验命题

三条从盘感里总结出来的命题——"健康的上涨回调少"、"放量冲高之后回调多"、"企稳之后会恢复原趋势"——算出事前条件概率之后，**三条全部反向**。

对应的纪律：

> 任何"事后看有迹可循"的命题，必须先算出**事前条件概率与 lift**，再决定采不采信。

（唯一一条在样本内外都成立的状态命题是"深度回撤之后结构破坏概率约 2 倍"，lift 2.0~2.4——但它也只被允许**发告警，不触发动作**。）

## 三、活下来的部件，以及它们各自的证据

| 部件 | 为什么留下 |
|---|---|
| **数据/对齐架构**：只用已收盘的高周期 K 线、事件驱动、回测实盘同源 | 无未来函数回归测试通过；模拟盘回放与回测入场逐笔一致 |
| **通道突破 + 量能门** 定义 regime | 通道周期 N 在 {10, 20, 30, 55} 上是一片**平台**（不是尖峰）；把量能门关掉，最短的那个 N 立刻崩掉 → 量能门是必要条件 |
| **regime 边沿立即入场** | 段内任何择时都不优于随机（三次独立检验） |
| **只在 regime 反向时离场** | 对随机出场的 z = 2.5 / 1.9 / 4.3 / 2.8，样本内外**首次同时** ≥ 2；长趋势段捕获率 95~97% |
| **很宽的灾难止损（4×ATR）** | 捕获率样本内 93% / 样本外 92%；止损宽度从 1.5× 放到 4×，被洗出的次数从 98 降到 6 |
| **反波动率仓位**（名义规模 ∝ 1/ATR%） | 样本内外各项指标都更优；更重要的是**单笔止损亏损被锁定为权益的一个恒定比例** |
| **执行禁区**（资金费结算前、宏观日历前后、强平爆发后） | 逻辑先验 + 一次实证：某个宏观数据发布时刻，两分钟内价格 −2.1% 且发生数千万美元级别的单向强平，**事前无任何可预判信号** |

## 四、周期分层的角色被彻底重新定义

这是 v0.3 → v1.0 最大的结构性变化：

| 层 | v0.3 的角色 | v1.0 的角色 |
|---|---|---|
| 高周期（4h） | 定方向 | **就是策略本身**：regime、入场、离场、仓位、止损全在这一层 |
| 中周期（1h） | 找结构、找 setup | **风险观测**：打标签、发告警、进记分卡，**不触发任何动作** |
| 低周期（15m） | 入场触发 | **执行层**：成交分辨率、禁区判定、滑点模拟，**不做决策** |
| 微观（1m / 逐笔） | — | **研究与事后核查**层 |

原则从"三层协同决策"变成了：**决策只在一个周期上发生，其余周期只负责观测和执行。**

每往下一层加一次决策权，就多一次被噪音污染的机会——而实测显示，这些额外的决策没有一次带来正信息。

## 五、必须接受的代价

一套诚实的趋势跟随系统，它的"缺点"不是 bug，是它的定义的一部分：

- **方向正确率约 38%，胜率约 39%**——利润全部来自少数长段；
- **预期最大回撤 40~50%**，而且这个回撤**来自方向正确率，不是来自止损宽度**——收窄止损不会改善回撤，只会砍掉捕获率；
- **牛市一定跑输持有**（实测样本内三年跑输基准很多），**熊市与震荡跑赢**。这是趋势跟随的本性，不是实现缺陷；
- 因此**不能设日内回撤停机**——它会把长趋势段切碎。

如果这些代价不可接受，那么应该换一类策略，而不是往趋势跟随上打补丁。绝大多数"改进"（回调入场、分批止盈、追踪止损）本质上都是在试图规避这些代价，而实测它们的代价是砍掉利润来源。

## 六、参数的来历必须逐条写下来

v1.0 明确列了一张表，说明每个参数**是怎么定的**：

| 类别 | 说明 |
|---|---|
| 样本内挑选 + 平台验证 | 通道周期 N、目标波动率 |
| 纯先验、从未扫描 | 量能倍数、ATR 周期、禁区窗口分钟数 |
| 阶梯测试 | 灾难止损倍数（3~6 之间的差异在噪声内） |

**"无任何参数经过优化"** 这句话之所以敢写，是因为有这张表撑着。

同时它诚实地标注了"敏感性未知"的项：量能倍数从未扫描过，禁区窗口从未回测过 PnL。这两项是已知的洞，不是被掩盖的洞。

配套的研究协议只有六条，但每一条都是从一次失败里长出来的：

1. 任何新规则必须先有**先验逻辑**，再在样本内检验，样本外复验，且对随机基准 **z ≥ 2 于样本内与样本外**；
2. 特征检验必须过**安慰剂标定 + FDR**；"样本外同号"和"逐年同号"**不算独立证据**；
3. **不调参**：参数只允许做"平台 / 尖峰"判定，不允许挑最优；
4. 记分卡里的"考试段"只报告不改，盲测段最后才跑；
5. 跨 regime 定义比较看期望与捕获率，**不看 z**（基准会塌陷）；
6. 任何"事后看有迹可循"的命题，先算事前条件概率与 lift。

---

## 七、这套方法论自己抓出了什么

值得记录的是，上面这套协议在自己的研究过程中**抓出了三次假阳性**：

- 一个通道参数在样本内 z = 2.0，但那是因为随机基准在那个 regime 定义下塌陷了；
- 一个趋势强度退出规则样本内 z = 6.7，样本外 **−0.67**；
- 用 iid 标准误（而不是聚类标准误）时，一次筛选放出了 193 对"显著"的配对。

如果没有这三条，v1.0 里会多出三个看起来有证据的错误部件。

---

## 八、一句话

> 一套设计得很漂亮的多周期框架，在四年数据上活下来的部分，比原设计**少得多**。写下"什么死了、怎么死的"，比写下"什么活着"更有价值——因为死掉的那些正是所有人第一次都会写的那些。
