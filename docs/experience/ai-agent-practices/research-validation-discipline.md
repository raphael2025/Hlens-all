# 用 AI 做定量研究的验证纪律

AI agent 极大地降低了"跑一个实验"的成本。
副作用是：它也极大地降低了**过拟合的成本**。一个晚上扫一万组参数、挑出最漂亮的那条曲线、写一份自信的报告——整个过程比人工快两个数量级，而统计上的错误率一点没降。

这份文档是一套"先验证、后相信"的纪律。它最初来自加密量化研究，但核心结构适用于任何"从历史数据里挑出一条规则并声称它有效"的工作。

---

## 1. 台账优先：开新研究前先查已测方向

最省钱的一条纪律，和统计学无关：

**维护一份"已测方向台账"，任何新研究开工前先查一遍。**

台账分三栏：

- ❌ **已严格证伪**（扣费 + placebo/OOS/多重检验之后仍然死）—— 别重挖。重挖不只是浪费时间，它还会**推高你的 trial 计数**，从而降低所有后续结论的统计显著性。
- ✅ **曾经活下来**（窄、脆，需要前向验证）—— 去做前向，不要再优化。
- 🔑 **反复验证的硬道理** —— 方法论层面的结论。

台账一行一条、可快查。每条不只写结论，还要写**"怎么死的 / 怎么活的 + 在哪验证的"**——让未来的你能判断这条判决的可信度，而不是盲目采信。

每轮研究结束必须更新台账。这是唯一能阻止"跨会话重趟死路"的机制。

---

## 2. 多视角交叉验证

单一 agent 的回测结果不可信——不是因为它算错，而是因为它和你共享同一套隐含假设。

一个实测有效的协议：每个重要假设必须通过多个**独立视角**：

1. 主 agent 的基础回测
2. 子样本切分 + 多重检验校正 + 扣除交易成本 + 聚类调整
3. **换一个数据源**重跑
4. 完整的反过拟合统计套件（见下一节）
5. 集成 + 多市场状态（regime）分解

**全部通过才能标记为已验证；任意一个反驳 → 证伪或改向。**

注意两点：

- 视角之间要真的独立。用同一份数据、同一份代码跑五遍不叫五个视角。
- **历史通过 ≠ 现在有效**。毕业闸门应该是"历史全套通过 **且** 前向 ≥30 天表现达标"，不是只看历史。

---

## 3. 反过拟合统计套件

不要手搓简化版。一个完整的套件至少要有六项，且它们**互不可替代**：

| 检验 | 防什么 | 典型门槛 |
|---|---|---|
| Deflated Sharpe (DSR) | 多重比较、厚尾 | DSR ≥ 0.95 |
| Probabilistic Sharpe (PSR) | 非正态下是否真超基准 | PSR > 阈值 |
| PBO (CSCV) | 样本内优化在样本外失效 | PBO < 0.50 |
| Block bootstrap | 脆弱的 Sharpe、被低估的回撤 | P(SR≤0) 低，且看回撤尾部 |
| Placebo / 置换检验 | 信号并不优于随机 | 差值置信区间不跨 0 |
| Walk-forward | 表现集中在某个时段 | 高比例 fold 为正 |
| 参数高原检测 | 孤立的参数尖峰 | 高原，而非孤峰 |

### 关键区分：selection-aware vs selection-blind

- **selection-aware**（DSR、PBO）：能"看见"你试了多少配置。
- **selection-blind**（bootstrap、walk-forward、placebo）：只看一条最终曲线，可以被 cherry-pick 欺骗。

**规则：任何一项 selection-aware 检验失败，强制判定过拟合。selection-blind 的漂亮结果不能洗白它。**

反过来，selection-blind 可以提出额外担忧（比如 bootstrap 揭示的真实最坏回撤远大于历史观测值），这些担忧要采纳。

### `n_trials` 是最常被隐瞒的数字

**量化研究里最少被报告的数，是"你一共试了多少组配置"。**

填 `n_trials` 时算的是**整个项目至今试过的配置总数**，不是"这一次网格的点数"。grid search 扫了 200 个点就是 200；如果这是第三轮网格，前两轮也要算进去。

不诚实填这个数，DSR 会系统性高估你的 edge。

**进阶**：标准 DSR 假设各次 trial 独立，但同一 regime 下的 trial 高度相关（实测平均相关系数可达 0.3+）。对高度相关的 trial 用朴素 DSR 会算错惩罚项——一个 120 次 trial 的网格，有效独立数可能只有个位数。做聚类感知的收缩（或用相关矩阵估有效自由度）能避免这个系统性偏差。

### 特征级和策略级是两件事

- **特征级**：IC / RankIC 筛选（注意用非重叠采样），回答"这个特征有没有信息"。
- **策略级**：上面那套反过拟合检验，回答"这套规则能不能交易"。

两者互补，不能互相替代。先用 IC 筛特征，再用统计套件做策略级最终验证。

**重要的是不要做第三套实现。** 同一个组织里出现两份独立实现的 DSR/PBO，最终一定会给出不一致的结论，然后没人知道该信哪个。选一个，合并进去。

## 4. 十五条实操铁律

这些是踩坑踩出来的，每一条背后都有一次真实的假阳性：

1. **z-score 必须滚动窗口（≥1 天）。expanding z-score 永久禁止**——它会让未来信息泄漏进标准化，曾把一个真实的负信号做成 Sharpe +51。
2. **少于 30 天的数据只能做 EDA**，不能当作 alpha 验证。
3. **Sharpe 要拆成 mean / std 两部分看**。std 异常低于市场基准往往意味着假 Sharpe（数据问题或前视泄漏）。
4. **交易集中度要主动反证**：n 笔交易里 >30% 集中在少数几天 = regime 巧合，不是 edge。
5. **样本外资产要过半**：3 个标的测、2 个失败 = 单标的假象，不能外推。
6. **子 agent 的报告必须主 agent 自己复现**，不能直接采信。
7. **全周期 Sharpe ≠ 滚动窗口 Sharpe**。必须拆窗口看，尤其看最近那一段。
8. **跨 regime 分裂（短期神、长期灾，或反之）= 策略本身不工作**，不是"需要择时开关"。
9. **二次因子融合经常破坏原始 alpha**。原始信号在 13 个窗口里 10 个为正，叠加第二个因子后掉到 1 个为正——这种情况很常见。
10. **"稳健"不能泛化到变体**。必须逐字复现原始参数；换一个调仓周期、换一个持仓数，都要重新验证。
11. **极端参数敏感 = 警示**。真 edge 应该是参数高原，不是孤峰。
12. **复现脚本本身也要逐行审计**。一行多余的赋值曾把 −88% 算成 +39504%。
13. **"短期极好 + 近窗衰减" 要看近窗**，不要被总体指标骗。
14. **有条件通过 ≠ 已验证**。全套统计过了，仍然要跑 ≥30 天 paper。
15. **历史全套通过 ≠ 当前 regime 有真 edge**。一个 DSR 0.997 / PBO 0.04 的策略，最近 180 天 Sharpe 可以是 −2.28。

## 5. 反复被验证的硬道理

方法论层面的结论，比任何具体策略活得久：

- **回撤是波动目标的线性旋钮，Calmar 近似守恒。** 控回撤 = 降仓位，不是花式择时。
- **紧止损有害（砍掉赢单），宽 ATR 移动止损有益。** 不是"止损一律有害"，是"止损宽度是个要优化的参数"。
- **"0 事件 / 0 信号" 先查数据管道 bug**，不要先怀疑假设。时间序列对齐问题曾让整条轨道显示 0 行。
- **简单 + 果断 + 让利润奔跑，碾压精细的二次择时**（等回调、低周期入场、阻力位止盈系统性地更差）。
- **先问"打得过无脑买入持有吗"**。宽基等权买入持有的 Sharpe 可以到 1 附近，极难被打败。
- **bootstrap 的最坏回撤常常接近历史 MDD 的两倍**。不能只看历史数字定杠杆。
- **合成数据 / 自己写的 generator 不可信**。合成订单簿上 100% 胜率的信号，在真实数据上胜率可能只有三成多。
- **历史正结果复现不出来 → 当初多半就是错的。** 不要用"市场变了"来解释；先假设是自己当初算错了。
- **公开后的 alpha 会衰减。** 公开指标的 IC 在发表后系统性下降。预期衰减，不要当永动机。
- **公开综述里的 ✅ 不是你自己的机器验证结果。** 同一个知识库里，综述层标"有效"的策略，在机器验证层可能全部标"过拟合"。以自己跑出来的为准。
- **指标好 ≠ 能赚钱。** 一个分类 precision 0.74 的信号，做成策略后 Sharpe 可以是 −2.46。

## 6. 仓位与风险（只记非常识部分）

- **实战永远不要 full-Kelly，half-Kelly 起步。** 50% 回撤是 full-Kelly 的常态，不是意外。
- **波动目标化本质就是分数凯利**：`f* = (μ/σ²)·(σ_target/σ)`。
- **永续合约的资金费率会缩放凯利分数**；负费率会放大甚至反转仓位方向。
- 引用风险约束凯利的文献时**核对 arXiv 编号**——这个领域有一篇被广泛误引的编号。

## 7. 一个范式转变

一条值得单独记下来的认知：

> 量化信号普遍存在滞后性，寻找"领先指标"本质上是在逆市场结构而行。

在花了两百多轮实验去找"某个链上指标突变领先于价格"之后，多个独立视角一致把它判为聚类假象。
转向之后的思路是：**识别当前状态，而不是预测下一刻**——用多周期结构 + 多维度证据判断"现在处于什么状态"，证据矛盾时保持静默。

这个转变和台账里的存活方向是同构的：活下来的低频趋势 / 截面 / carry 类方法，本质都是"在确认后的状态上持有"，而不是抢毫秒级的领先信息。

同时注意别过度解读：某个状态识别模板出现过一次漂亮的实战命中，**一次命中不等于验证通过**。世界观可以保留，具体分类器仍然要走完整流程。

---

## 8. 为什么这些要写进 agent 记忆

因为 AI 额度有限，研究跨多次会话。**不沉淀就会重趟死路**：

- 每完成一个方向 → 更新台账（三栏，一行一条）
- 详细过程另存 → 分项报告
- 经验写"怎么死的 / 怎么活的 + 在哪验证的"，不只写结论
- **开任何新研究前，先读台账**

这条流程本身，比台账里的任何一条结论都更有价值。
