# 当交付物是"这条路走不通"：一个以负结果为主的研究项目复盘

一个连续几天高强度推进的单标的策略研究项目，绝大部分产出是负结果：测过的方向性信号，几乎没有一个活下来。这份文档记录那条证伪链是怎么一步步走完的、最后什么东西活了下来、以及项目怎么从"找信号"转向"控风险"。

负结果最容易被浪费——不写下来，半年后会有人（很可能是自己）原样再测一遍。

---

## 一、项目自我定位先摆正

项目说明文件开头就写着：

> 这不是一个软件产品，没有要发布的应用。交付物是**关于哪些策略/风控配置真的有效的经验证据**。

这句话决定了后面所有取舍：负结果和正结果同等重要，"测完并排除一条路线"本身就是交付。

---

## 二、证伪链：一条一条被排除的方向性候选

### 2.1 第一次修正：一个经典的重叠采样错误

搭了一套**独立于交易逻辑**的"状态质量评估"框架——不套进任何交易系统，直接检验"知道当前状态"能不能显著预测"未来 N 根 K 线的收益率（方向型）"或"未来 N 根 K 线的波动率（强度型）"。

第一次跑完，七个候选状态信号在所有前瞻窗口上**全部** p<0.05，大部分 p<0.0001。好到不真实——确实不真实。

根因是**前瞻窗口重叠**：滚动计算的"未来 N 根收益率"，相邻样本点有 N-1 根 K 线是共享的，样本根本不独立，t 检验用的样本量是虚的。

修正方法：**每隔 N 根才采一个样本点**，保证前瞻窗口互不重叠，牺牲样本量换真实独立性。

修正之后，同一批信号里方向型的全部变成不显著，只剩下一个波动率类的强度型信号站得住。

> 这是这类研究最容易漏掉、也最容易一次性毁掉全部结论的坑：**"显著到可疑"永远先怀疑采样方式，而不是先庆祝。**

### 2.2 逐条排除

修正之后，候选一个个上，全部按"非重叠采样 + 多重比较校正"处理：

| 候选家族 | 结果 |
|---|---|
| 两条均线的相对位置（趋势 regime） | 不显著 |
| 均线斜率背离、回踩深度（肉眼在图上总结出的具体模式） | 均值方向大多符合直觉，但噪声太大，不显著 |
| 系统扫描"加一条快线"的所有周期 | 原始 p<0.05 的次数**比随机期望还少**，校正后 0 条存活 |
| 指数均线替代简单均线 | 十几次检验 0 次显著 |
| 纯结构（突破前高/跌破前低） | 校正后 0 条存活 |
| 动量自相关、跨周期背离、放量方向性、资金费率分位数 | 校正后 0 条存活 |
| 隐马尔可夫三状态 | 不显著 |

**多重比较校正是这一段的主角**。有几次如果不做校正，"某个周期某个窗口 p=0.043"会被当成发现——实际上那就是几十次检验里随机蹦出来的一个。日志里反复出现同一句自我提醒：

> N 次检验在完全没有真实效应的原假设下，大约期望有 N×0.05 次假阳性。实测到的"显著"次数如果落在这个量级内，那不是证据，是噪声。

还有一个更微妙的判据：**哪一个窗口显著，在样本内/样本外/全样本之间换来换去**——不是同一个窗口稳定显著。这正是噪声导致偶发显著的典型特征。

### 2.3 一次"看起来扛住了"的案例，以及它是怎么翻车的

中途出现过一个明显比其它候选更像真信号的规则（来自用户多年实盘习惯的具体描述：均线方向 + 道氏结构确认 + 动量指标零轴上方金叉）。它的表现确实不一样：

- 前瞻收益率均值在四个窗口上**方向完全一致**地高于全样本基准（此前测过的东西都是正负乱跳）；
- 在自建引擎上是正的；
- **在更可信的独立引擎里复核之后依然是正的**——当天唯一扛住交叉验证的信号。

然后连着两关把它毙了：

1. **多重检验校正**：把当天所有独立试验汇总成一个试验池（一百多次），对观测到的最优结果做 Deflated Sharpe 校正，概率接近 0。翻译成人话：**在已经试了一百多次这个前提下，哪怕当前最好的结果，也没强到能确信它不是蒙出来的。**
2. **真样本外**：额外下载了一段**在此前所有测试中从未被碰过**的近期数据，原样重跑——直接转负。

两条独立证据指向同一个结论。日志里给出的三条教训：

1. **"过了交叉验证"不等于"经得起考验"。** 交叉验证只解决"自建引擎乐观偏差"这一个问题，不解决"过拟合到这段历史"这个更根本的问题。两个是完全不同的检验，都要做。
2. **统计校正要排在"花大力气做真样本外"之前。** 校正便宜、样本外贵；先做便宜的那关，可以少浪费很多时间。
3. **用户多年实盘整体盈利这件事仍然成立，但 edge 很可能不在"可以被写成规则"的那部分**——更可能来自临场判断、什么时候不做、仓位微调的直觉，这些回测测不出来。

这个规则最后被标记为"样本外验证失败，不再推荐"，但**保留在方法目录里作为反面教材**：一个过了交叉验证却过不了真样本外的典型案例。

### 2.4 顺带一次干净的外部复现失败

文献调研中找到一个公开宣称"年化 30%+、Sharpe 1.5+"的时段性策略（特定 UTC 时段的流动性真空效应）。立刻在自己的数据上复测：均值接近 0，t 值为负，完全不显著，年化换算是负的——**和原始回测的结论完全相反**。

这次失败是"干净"的，因为它和一个已有的学术共识吻合：这类可预测性会随市场成熟而衰减，而复测用的样本区间比原文更靠后、市场更机构化。

> **公开回测的复现失败，本身就是一条值得写下来的结论**，尤其当失败方向可以被一个独立的理由解释时。

## 三、活下来的那一条

在几十次检验的废墟里，有一类东西反复站住：**波动率是可预测的**（高波动之后大概率还是高波动），而方向不可预测。

它之所以可信，不是因为某一次 p 值特别小，而是因为**四个互相独立的角度都指向同一个结论**：

1. 最早的状态质量检验里，唯一扛住重叠采样修正的就是波动率分位数；
2. 后来的特征 IC 扫描里，扛住多重比较校正的全部是"预测未来波动率大小"的特征，没有一个方向型的；
3. 换四种数学上不同的波动率估计量分别重算，在短窗口上**全部一致显著**；
4. 组合特征在真样本外**比样本内还强**，没有衰减迹象。

两个附带发现值得单列：

- **组合特征第一次样本外失败，但失败得很有信息量。** 四个特征加权组合，样本内 IC 很高，样本外却不显著。拆开看单个特征发现：两个特征样本外**符号直接反了**，另外两个符号一致且更强。**不是"大方向错了"，是混进了两个不稳定成分拖累了稳定成分。** 去掉那两个重新组合，样本外才真正站住。——拆开看，比看总分有用。
- **最简单的估计量反而最好。** 理论上统计效率更高的几种基于开高低收的波动率估计量，预测能力反而不如最朴素的收盘价指数加权版本。结论：**"估计当前波动率"和"预测未来波动率"是两个不同的任务**，当前估计更精确不代表预测能力更强。这一轮搜索的价值是把已有结论的可信度又抬了一层，而不是找到新的改进空间——**"没找到更好的"也是结果。**

## 四、一个解释了为什么会这样的框架性认知

调研中捡到一条把整件事串起来的结论：

> 主动管理基本法则：**信息比率 ≈ 信息系数 × √广度**。

这个项目只做**单一标的、只判断方向**，广度约等于 1。同样的信息系数，换算出来的可实现风险调整收益天然比多资产截面策略低一大截。**不是方法有问题，是这个赛道本身的天花板更低。**

与之呼应的是文献层面的共识：加密市场里真正有严谨证据支撑的量化优势，在**截面选币**和**carry（资金费率/基差）**上，不在单一资产的方向性择时。前者赚的是相对强弱，后者赚的是结构性风险溢价，**两者都不需要判断方向**。

于是这一轮的收尾不是"我们运气不好"，而是：**这个具体问题的性质如此**，继续在同一个框架内加班没有边际收益。

## 五、转向：从"判断方向"到"控制仓位"

负结果的真正价值，是它把资源逼向了对的地方。

原先的框架是"多头 / 空仓 / 空头三态轮动"——信号一转弱就整个清仓。在一个长期上涨的标的上，这等于频繁下车，踏空的涨幅远超靠方向判断赚回来的钱。三方对比（真实信号 / 随机方向 / 买入持有）给出的诊断很明确：**问题不是"看错方向"，而是"频繁进出的成本 + 踏空，抵消掉了看对方向的那点优势"。**

新框架：**底仓常驻 + 只用波动率调节仓位大小，不做方向判断、不清仓、不做空**。把"要不要在场内"的二元判断，换成"在场内待多重的仓位"的连续判断。

两处关键设计都是被前面的负结果逼出来的：

1. **仓位权重不掺杂任何方向判断**——因为方向类信号反复测下来没有站得住的统计证据，而波动率预测有。"方向没验证过就先别用"。
2. **去掉拍脑袋的固定比例硬止损**，改用由极值理论倒推出的杠杆上限作为唯一防线。逻辑是：仓位既然已经被上限锁死在"遇到历史最坏的一根 K 线也不至于被强平"的范围内，就不需要再叠一层会被正常波动误触发的止损。上一版正是被这层误加的止损坑过一次——一次极端单日暴跌触发硬止损后，因为没有重新入场逻辑，策略在之后的几年里一直空仓，错过了整段行情。

### 结果与诚实定位

新版本相对旧版本：风险调整收益基本持平，**最大回撤接近减半，且旧版那次实打实的强平事件不再出现**。样本外那段时间标的本身是下跌的，策略跌得比买入持有少——**不是因为判断对了方向（它根本没有方向判断），而是波动率模块在市场变得不稳定时正确地把仓位调小了。**

日志里的定位写得很克制：

> 这不是一个"能赚钱跑赢买入持有"的策略。样本外它和买入持有一样在亏钱，只是亏得少。它的价值是**风险管理**：同样暴露在同一个 beta 下，回撤和尾部风险明显更可控。

还顺手记下一条容易被忽视的风险类型差异：**加了杠杆的常驻仓位策略，即使平时仓位控制得当，也可能在极端单次崩盘里被强制平仓——这是现货买入持有完全不会遇到的风险来源，不能只比回撤数字大小就认为两者等价。**

## 六、把负结果写成资产的几条做法

1. **给每个方法一个状态**（待测 / 测试中 / 已采纳 / 已否决），否决的也留在目录里，附上否决理由和证据文件。
2. **否决理由要写机制，不只写数字**。"经典参数是为'已在趋势中的持仓'设计的，套到'趋势刚确认、还没走出局部新高'的入场时点就不适用"——这样的理由半年后还能用；"Sharpe 是负的"不能。
3. **保留反面教材**。过了某一关却倒在下一关的案例，比从头就失败的案例更有教学价值。
4. **区分"测出无效"和"数据不够回答这个问题"**。日线数据只有不到两千根、regime 平均几百根才翻转一次时，"不显著"更准确的说法是"这个样本量回答不了这个问题"，不等于"确定没用"。这个区分必须写清楚，否则会被后来人误引为强结论。
5. **别把结论扩大**。测了几个经典候选不显著，不等于"这个市场没有方向性 alpha"——只能说"这几个、在这个尺度上、用这份数据，测不出来"。

> 收尾的一句话：**一个只交付负结果的研究周期，如果把"为什么走不通"写清楚了，它的价值高于一个交付了未经证伪的正结果的周期。**
