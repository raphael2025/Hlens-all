## 证据等级约定

| 等级 | 含义 |
|---|---|
| ✅ 高 | 顶级期刊同行评审、官方机构一手数据、或交易所官方文档(机制事实) |
| ⚠️ 中 | 机构研究报告(AQR/MSCI/Robeco/Kaiko/Amberdata 等)、SSRN 工作论文、主流财经媒体一致报道 |
| ❌ 低 | 数据商营销图表、交易圈共识、独立博客、来源不明的网络说法 |

## 贯穿全部研究的一条主线

> **一个指标/因子/策略越流行,它的证据强度往往越弱;而证据越弱,越可能在最需要它的那一刻失灵。**

五个实例(详见各文档):

| 对象 | 表面 | 真相 |
|---|---|---|
| 链上顶部指标(MVRV/Pi Cycle 等) | 历史上很准 | 2025-10 真正的顶部**全部没响** |
| BTC 跟随全球 M2 滞后 10–12 周 | 相关性 0.85 | 滞后期从 56 天到 102 天都有人说 = 过拟合 |
| 已发表因子 | t > 2 显著 | 发表后收益**衰减 58%** |
| Regime 择时 | 回测夏普 1.74 | 用诚实的过滤概率只剩 **0.78** |
| 加密因子回测 | 年化惊人 | 等权幸存者偏差**年化 62.19%** |

失灵方式相同:**你以为在检验假设,其实在拟合历史。**

对策也相同:先写下假设再看数据;留出完全不碰的样本;永远问"这个结论在什么检验框架下成立"。
